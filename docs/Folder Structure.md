# Project Folder Structure.
The project has the following folder structure:
 - **code**: contains projects source code.
   - **code/manager**: contains the source code for the manager. This is the python manager module.
   - **code/agents**: contains the source code for all the agents. The code here is likely to run in a Google Colab Instance(not sure yet).
 
- **tests**: contains tests for the source code.
  - **tests/manager**: contains tests for the manager source code.
  - **tests/agents**: contains tests for the agents source code. This is likely to run in a Google Colab Instance(not sure yet).

- **docs**: contains project documentation.
  - **docs/Notes**: my personal notes. How to implement x and y. The design stuff is in the docs LaTeX repo.
