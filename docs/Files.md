# Project Root
- **install.sh**: used to "install" the project. Copies the content of the code folder to ~/Builds/MicroRTS/py
- **pyproject.toml**: settings for the pytest packaage used to run tests.
- **Changes.md**: used to track important changes.
- **Issues.md**: used to track important bugs/issues.
- **TODO.md**: used to track important stuff to do in the development process.
- **setup.sh**: used in the initial setup of the git repo. Intended to be used right after the git repository has been created.

# code
- **config.py**: contains settings for the whole project. Where there is a need to use a certain setting, import this file.
